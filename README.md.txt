# Thin-Film Transfer Matrix Method (TMM) for Photonic Structures

This project implements the Transfer Matrix Method (TMM)
for modeling optical behavior of multilayer thin-film
photonic structures.

Applications include:
- thermophotovoltaics (TPV)
- spectral engineering
- selective emitters
- optical coatings
- photonic energy systems

## Example Result

![Emissivity Spectrum](figures/emissivity_spectrum.png)

## Features

- Spectral reflectance calculations
- Emissivity calculations
- Thickness sweep optimization
- Angular optical analysis
- MATLAB implementation

## Methodology

The optical response is calculated using the Transfer Matrix Method (TMM) for stratified multilayer media.
